Este plugin proporciona el entorno de ejecución nativo de OpenCV 4.8.0 que utilizan las API de procesamiento de imágenes de AutoJs6. AutoJs6 lo detecta automáticamente después de instalarlo y habilitarlo.

El plugin no dispone de una interfaz de usuario independiente. Instálelo únicamente desde una fuente de confianza. Si se actualiza después de que AutoJs6 haya cargado OpenCV, reinicie AutoJs6 antes de continuar con el procesamiento de imágenes.
