Ce plugin fournit l'environnement d'exécution natif OpenCV 4.8.0 utilisé par les API de traitement d'image d'AutoJs6. AutoJs6 le détecte automatiquement après son installation et son activation.

Le plugin ne possède pas d'interface utilisateur autonome. Installez-le uniquement depuis une source fiable. Si le plugin est mis à jour après qu'AutoJs6 a chargé OpenCV, redémarrez AutoJs6 avant de reprendre le traitement d'images.
