Плагин OpenCV (OpenCV Plugin) предоставляет нативную среду выполнения OpenCV 4.8.0, на которой построена обработка изображений в AutoJs6. API для работы с изображениями, такие как поиск изображений, поиск цвета и сопоставление с шаблоном, выполняют вычисления средствами OpenCV; после установки плагина хост AutoJs6 с поддержкой подключаемого OpenCV может пользоваться этими функциями как обычно, без какой-либо дополнительной настройки в скриптах.

### Как пользоваться

1. Скачайте со страницы [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-OpenCV/releases) APK плагина, подходящий для устройства, и установите его на устройство с AutoJs6; если сомневаетесь, выберите пакет `universal` или загляните в раздел `Как выбрать APK` ниже.
2. Откройте центр плагинов AutoJs6 и убедитесь, что плагин `OpenCV` распознан и включен.
3. Пишите и запускайте скрипты как обычно: когда скрипт обращается к API для работы с изображениями, AutoJs6 автоматически загружает нативную библиотеку OpenCV из плагина; код скриптов менять не нужно.
4. После обновления или переустановки плагина полностью выйдите из AutoJs6 и запустите его заново, прежде чем снова выполнять скрипты с изображениями, чтобы новая нативная библиотека вступила в силу.

Если плагин не появился в центре плагинов, сначала обновите AutoJs6 до свежей версии (внутренняя сборка 5237 или новее). Сам плагин поддерживает устройства с Android 7.0 (API 24) и выше.

### Как выбрать APK

Каждый выпуск включает 5 APK, которые различаются только набором архитектур встроенных нативных библиотек:

| Пакет | Кому подходит |
|---|---|
| `arm64-v8a` | Подавляющее большинство современных телефонов и планшетов Android (64-битный ARM); выбирайте в первую очередь |
| `armeabi-v7a` | Более старые 32-битные устройства ARM |
| `x86_64` | 64-битные эмуляторы x86 и немногочисленные устройства x86 |
| `x86` | 32-битные эмуляторы x86 и немногочисленные устройства x86 |
| `universal` | Содержит все 4 архитектуры и имеет наибольший размер; работает на любом устройстве и остается надежным выбором, если вы не уверены |

Устанавливайте плагин `universal`, если APK Builder в AutoJs6 должен собирать приложения для нескольких архитектур: плагин для одной ABI может предоставить OpenCV только для своей архитектуры. Если по ошибке установлен пакет для одной ABI, не соответствующий устройству, плагин не сможет предоставить пригодную нативную библиотеку; переход на пакет `universal` решает проблему.

### Быстрая самопроверка

Убедитесь, что OpenCV включен в центре плагинов AutoJs6, перезапустите AutoJs6 и выполните этот скрипт. `images.initOpenCvIfNeeded()` действительно запускает обнаружение плагина, проверки совместимости и загрузку нативной библиотеки, а не только читает метаданные:

```javascript
images.initOpenCvIfNeeded();

const Build = android.os.Build;
const Process = android.os.Process;
const Core = org.opencv.core.Core;
const processAbis = Process.is64Bit()
    ? Build.SUPPORTED_64_BIT_ABIS
    : Build.SUPPORTED_32_BIT_ABIS;
const processAbi = processAbis.length > 0 ? processAbis[0] : "unknown";

console.log("OpenCV version: " + Core.getVersionString());
console.log("Process ABI: " + processAbi);
```

При успехе выводятся `OpenCV version: 4.8.0` и ABI процесса, например `arm64-v8a`. Если загрузка не удалась, проверяйте по порядку: установите пакет `universal`, обновите AutoJs6 до внутренней сборки 5237 или новее, затем полностью закройте и перезапустите AutoJs6.
