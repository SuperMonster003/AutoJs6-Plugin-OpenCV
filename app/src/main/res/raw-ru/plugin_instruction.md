Этот плагин предоставляет нативную среду OpenCV 4.8.0 для графических API AutoJs6. После установки и включения AutoJs6 обнаруживает его автоматически.

У плагина нет отдельного пользовательского интерфейса. Устанавливайте его только из надежного источника. Если плагин обновлен после загрузки OpenCV, перезапустите AutoJs6 перед продолжением обработки изображений.
